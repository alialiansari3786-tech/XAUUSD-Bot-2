## Bugs Fixed

### 1. ✅ Missing Telegram Sync Wrappers
**Location:** `src/integrations/telegram_bot.py`  
**Issue:** `main.py` called `send_status_update_sync()` and `send_error_alert_sync()` but these methods didn't exist.  
**Symptoms:** Bot crashes on startup with `AttributeError: 'TelegramNotifier' object has no attribute 'send_status_update_sync'`  
**Fix:** Added missing sync wrapper methods:
- `send_status_update_sync()`
- `send_error_alert_sync()`

### 2. ✅ Asyncio Event Loop Deprecated (Python 3.10+)
**Location:** `src/integrations/telegram_bot.py:290-308`  
**Issue:** Used deprecated `asyncio.get_event_loop()` which raises warnings/errors in Python 3.10+ (GitHub Actions runs Python 3.11)  
**Symptoms:** `DeprecationWarning` or `RuntimeError: There is no current event loop in thread`  
**Fix:** Replaced with modern `asyncio.run()` pattern with proper loop detection and thread pooling fallback

### 3. ✅ yfinance Column Mismatch
**Location:** `src/core/data_fetcher.py:142-146`  
**Issue:** Hard-coded `df.columns = ['Open', 'High', 'Low', 'Close', 'Volume']` crashes when yfinance returns extra columns (Dividends, Stock Splits) or different formats  
**Symptoms:** `ValueError: Length mismatch: Expected axis has 7 elements, new values have 5 elements`  
**Fix:** Implemented intelligent column mapping that:
- Handles varying column names (case-insensitive)
- Filters to OHLCV only
- Adds Volume=0 for forex pairs without volume data
- Validates at least OHLC present before proceeding

### 4. ✅ Timezone-Aware Comparison Error
**Location:** `src/core/data_fetcher.py:73-82`  
**Issue:** Compared timezone-naive `datetime.now()` with timezone-aware timestamps from yfinance, causing `TypeError: can't subtract offset-naive and offset-aware datetimes`  
**Symptoms:** Bot crashes when checking cache age  
**Fix:** Added timezone detection and proper UTC normalization before comparison

### 5. ✅ Wrong Error Alert Method Call
**Location:** `src/main.py:204`  
**Issue:** Called async `send_error_alert()` directly instead of sync wrapper  
**Symptoms:** Coroutine was never awaited, error notifications silently fail  
**Fix:** Changed to `send_error_alert_sync()`
